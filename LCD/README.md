# LCD Experiments

This folder contains three experiments with a 16×2 character LCD: a basic message and timer, moving text with a custom smiley, and a short animated story with a character, wall, explosion, scrolling text, and loading bar.

## Code used

All sketches use the `LiquidCrystal` library. They position text with `setCursor()`, refresh scenes with `clear()`, and create pixel graphics with `createChar()`. Loops, delays, and alternating custom characters produce the animations.

## What I learned

- How to initialize and write to a 16×2 LCD.
- How LCD rows and columns are addressed.
- How to design custom 5×8 pixel characters.
- How loops and timing can create simple animations and stories.
