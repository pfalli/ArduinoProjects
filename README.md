# Arduino Projects

A collection of small Arduino projects exploring LEDs, sensors, displays, joysticks, RFID, and simple interactive games.

## Projects

- [Traffic Lights](trafficLights/) — controls three LEDs in a timed red, yellow, and green sequence.
- [Thermometer](thermometer/) — measures temperature with a thermistor and displays it on a 16×2 LCD.
- [RFID Access System](RFID/) — reads RFID cards, checks access, displays status, and controls a servo lock.
- [Mouse / Joystick Reader](mouse/) — reads a joystick's two axes and push button through the Serial Monitor.
- [LCD Experiments](LCD/) — displays text, custom characters, movement, and a short animated story.
- [Joystick LCD Games](joystick/) — moves a custom character and implements Snake on a 16×2 LCD.
